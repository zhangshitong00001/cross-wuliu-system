# PR-001: 修复下载功能 + 补充批量上传模板

## 变更说明

修复项目中所有下载功能无法使用的问题，并为预警管理和用户管理页面新增批量上传模板下载及导入功能。

## 修改文件清单

| 文件 | 变更类型 | 说明 |
|------|---------|------|
| `static/index.html` | 修改 | 修复导出功能，添加 `responseType: 'blob'` |
| `app/routes/alert.py` | 修改 | 新增预警批量导入模板下载 + 导入路由 |
| `app/routes/auth.py` | 修改 | 新增用户批量导入模板下载 + 导入路由 |
| `app/services/__init__.py` | 修改 | CSV导出增加UTF-8 BOM，处理复杂类型 |
| `app/__init__.py` | 修改 | CORS配置暴露 `Content-Disposition` 头 |

## 问题与修复

### 问题1：导出（CSV/JSON下载）完全无法使用

**根因**：前端 `exportData()` 调用 axios 未指定 `responseType`，默认按JSON解析。后端返回 `Content-Type: text/csv`，axios在内部转换时报错，走catch分支显示"导出失败"。

**修复**：POST请求添加 `{ responseType: 'blob' }`，直接以Blob处理响应并触发浏览器下载。

### 问题2：部分页面导入按钮无对应后端路由

**根因**：预警管理(`alerts`)和用户管理(`users`)页面的 `pageConfigs` 中存在 `formFields`，前端显示了导入按钮和模板下载入口，但后端未实现对应路由，导致请求404。

**修复**：
- **预警管理**：新增 `GET /list/import/template`、`POST /list/import`
- **用户管理**：新增 `GET /users/import/template`、`POST /users/import`

模板字段与当前页面展示的字段名称一致。

### 优化项

- **CSV编码**：增加UTF-8 BOM（`﻿`），确保Excel正确识别中文字符
- **数据类型**：处理嵌套dict/list自动转JSON字符串，None转空字符串
- **CORS暴露头**：添加 `Content-Disposition` 到 `expose_headers`，前端可读取文件名

## 影响范围

- 所有列表页面（19个）的CSV导出功能
- 预警管理、用户管理页面新增批量导入能力
- 不影响现有数据和数据库结构
