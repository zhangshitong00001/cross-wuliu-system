## Project Overview

跨境物流管理系统 (Cross-Border Logistics Management System) — a Flask + Vue.js SPA covering the full logistics chain from Chinese cloud warehouses to 408 collection points in Almaty, Kazakhstan. Built as a single-page application with Vue 3 CDN + Bootstrap 5 on the frontend, Flask + SQLAlchemy + PostgreSQL on the backend.

## Key Design Decisions

- **Authentication**: Dual approach — Flask-Login (session-based for server-rendered) + Redis token-based (for SPA API calls). Tokens stored in localStorage, sent via `Authorization: Bearer <token>` header. The `before_request` hook in `app/__init__.py` auto-logins users from tokens.
- **Redis**: Used for captcha storage (`captcha:{code_id}`), session tokens (`session:{token}`), and login fail counters (`login_fail:{ip}`). All with TTL.
- **i18n**: Custom JS i18n system (no library). Translations stored in `I18n.translations` object (zh/en). Language stored in localStorage and applied via CSS class + custom events.
- **Frontend**: All-in-one SPA in `static/index.html`. Vue 3 CDN, no build step. Pages are driven by `pageConfigs` object that defines columns, form fields, and API endpoints per page. A single generic list/detail/edit template handles all CRUD pages.
- **Soft Delete**: All models use `is_deleted` integer flag (0/1) instead of hard deletion.
- **Operation Logs**: Every create/update/delete operation across all modules writes to `operation_logs` table.
- **Excel Import**: Unified import system via `app/utils/excel_import.py`. Each module exposes `POST /api/{module}/import` (upload + validate + batch insert) and `GET /api/{module}/import/template` (download template). Frontend provides a shared import dialog with drag-and-drop, template download, and result display.

## Route Pattern (CRUD Blueprint)

Every business module follows this pattern:
- `GET /api/{module}` — paginated list with keyword/status filters
- `POST /api/{module}` — create record
- `GET /api/{module}/<id>` — get detail
- `PUT /api/{module}/<id>` — update record
- `DELETE /api/{module}/<id>` — soft delete (set is_deleted=1)
- `POST /api/{module}/<id>/{action}` — custom action (confirm, start, complete, etc.)
- `POST /api/{module}/import` — Excel批量导入
- `GET /api/{module}/import/template` — 下载导入模板

All routes use `@login_required` from Flask-Login.

## Database

PostgreSQL 16, connected via `psycopg2`. Connection pool: 10 connections, recycle at 3600s.

## Running the Application

```bash
# Install dependencies
pip install flask flask-sqlalchemy flask-cors flask-login psycopg2-binary redis captcha openpyxl pandas

# Start with DB initialization (creates tables + default users/roles)
python run.py --init-db

# Normal start
python run.py --host 0.0.0.0 --port 5000
```

Default admin: `admin` / `admin123`
